## Rækkefølge pr. migration (som 00212–00220)
1. Forhåndstjek (read-only, se nedenfor).
2. Merge branchen lokalt på main. Push ikke endnu.
3. Tilføj nummeret til allowlisten i `scripts/prod-apply-migration.ts`.
4. Kør migrationen:

   ```bash
   npm run prod:apply-migration -- <nr> --approved-by-henrik
   ```

5. Efterkontrol (read-only).
6. Kør gates: `tsc`, `check:rls-matrix` og `check:rbac`.
7. Push. Deploy sker først nu, så koden aldrig kører uden sit skema.
8. Kør målrettede UI-tests mod staging.
